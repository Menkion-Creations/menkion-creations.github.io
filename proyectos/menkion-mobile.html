Menkion Mobile.

Una propuesta de experiencia móvil propia con una base Android segura.

Visión del proyecto

¿De qué se trata?

Menkion Mobile es una línea de exploración a futuro: cómo llevar una identidad visual y una experiencia propia a dispositivos móviles aprovechando una base Android que preserve sus mecanismos de seguridad.

Estado actual
  • Concepto de interfaz y experiencia propios
  • Investigación de arquitectura híbrida sobre Android
  • Sin versión instalable disponible
Lo que viene

Próximos pasos

Aún no existe una versión distribuible. Antes de implementar un sistema móvil, será necesario validar compatibilidad de dispositivos, mantenimiento y requisitos de seguridad.
